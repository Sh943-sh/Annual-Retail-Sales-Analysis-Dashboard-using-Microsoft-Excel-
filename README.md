Project Name: Annual Retail Sales Analysis Dashboard using Microsoft Excel                                                                                                                             
• Analyzed annual retail sales and order data to evaluate monthly sales trends and business performance.

• Created interactive dashboards to compare sales performance by gender, age group, and customer demographics. 

• Analyzed order status, including Delivered, Cancelled, Returned, and Refunded orders. 

• Identified the Top 5 performing states and evaluated sales distribution across different online sales channels. 

• Used interactive Slicers and Pivot Charts to filter and visualize data by Month, Channel, and Product Category.  

• Tools & Technologies: Microsoft Excel, PivotTables, PivotCharts, Slicers, Combo Charts, Pie Charts, Bar Charts, Data Cleaning, Data Processing,                     Data Analysis, Data Visualization.
